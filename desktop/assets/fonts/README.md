# Pretendard

Unmodified Pretendard v1.3.9 OTF files. The app embeds SemiBold (body) and Bold (headings); Regular is retained as a source asset.

- Source: https://github.com/orioncactus/pretendard/tree/v1.3.9/packages/pretendard/dist/public/static
- Copyright: Kil Hyung-jin, 2021. Reserved Font Name: Pretendard.
- License: SIL Open Font License 1.1; full text in [LICENSE.txt](LICENSE.txt).

The app loads these embedded fonts privately for its own process. No system font installation or network connection is needed. The full copyright notice and license are embedded in the standalone EXE. Font license in the tray menu opens a text copy in the app data folder; `--licenses` also writes the embedded text to stdout when redirected.
