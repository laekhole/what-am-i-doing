제목: waid - Orca·Codex·Claude Code의 작업과 답변을 한눈에 보는 Windows 앱
등록 유형: Show
URL: https://github.com/laekhole/what-am-i-doing

본문:

내가 뭐하고 있었지?

Claude Code에 화면 수정을 맡기고, Codex에는 API를 고치게 하고, 다른 세션에서는 문서를 정리합니다. 잠깐 다른 일을 하고 돌아오면, 어디까지 했는지 다시 짚으려고 각 창의 요청과 답변을 확인하게 됩니다.

그때 볼 작은 창을 만들었습니다. **waid(what am I doing?)**는 프로젝트, 최근 요청, 에이전트·모델, 로그에서 확인한 상태를 모아 보여주는 Windows 앱입니다. 카드를 펼치면 마지막으로 기록된 답변도 읽을 수 있습니다.

현재 지원 대상은 **Orca, Codex, Claude Code 세 가지**입니다. Orca 안에서 돌리는 Codex·Claude Code 세션도 함께 봅니다.

[세션을 모아 보는 화면](https://github.com/laekhole/what-am-i-doing/blob/main/assets/screenshots/sessions-ko.png) · [요청과 답변을 펼친 화면](https://github.com/laekhole/what-am-i-doing/blob/main/assets/screenshots/expanded-en.png) · [파란 마스코트](https://github.com/laekhole/what-am-i-doing/blob/main/assets/waid-mascot.png)

두 화면은 샘플 데이터로 만든 앱 화면입니다. 펼친 화면은 최신 소스 빌드의 영어 UI이고, 공개 v0.2.0은 한국어 UI입니다.

### 이렇게 쓰면 됩니다

위 샘플 화면의 세 작업을 예로 들어볼게요.

- **결제 화면 / Claude Code:** 키보드 이동과 오류 메시지를 개선하는 작업. 답변이 기록되어 **내 차례**입니다.
- **로그인 API / Codex:** 로그인 세션 만료 후 재시도 처리. 아직 **작업 중**입니다.
- **설치 문서 / Claude Code:** 설정 방법을 한국어로 정리하는 대화. 화면에는 **유휴**로 표시됩니다.

먼저 결제 화면 세션을 보면 되겠다는 판단을 한 창에서 할 수 있습니다. `2열`을 해제하고 카드 제목 부분을 누르면 맡긴 요청과 마지막 답변이 펼쳐집니다. 어떤 수정을 했다는 답변인지 읽고, 원래 세션으로 돌아가 실제 변경 내용을 확인하거나 다음 요청을 보내면 됩니다.

Orca에서 실행 중인 로컬 세션은 연결이 확인될 때 에이전트 로고나 `세션 열기`로 돌아갈 수 있습니다. 목록에 보이는 모든 터미널 탭으로 자동 이동하는 것은 아니며, 지원되는 창과 세션 연결이 필요합니다.

### 처음 실행부터 세션 정리까지

1. [v0.2.0 릴리스](https://github.com/laekhole/what-am-i-doing/releases/tag/v0.2.0)에서 `waid-v0.2.0-windows-x64.exe`를 받아 실행합니다. Windows 10/11 x64용이며 설치 프로그램이나 별도 런타임이 필요 없습니다.

2. waid를 켠 뒤 평소 쓰던 Orca·Codex·Claude Code에서 새 요청을 보냅니다. waid는 기존 로컬 로그를 읽습니다. waid에 API 키를 넣거나 대화를 복사할 필요는 없습니다.

3. 프로젝트 이름, 최근 요청, 모델과 상태를 확인합니다. 목록은 약 2초마다 갱신됩니다. 시작 전에 진행하던 대화는 처음에 `미확인`일 수 있습니다. 새 요청이나 답변이 로그에 기록되면 상태가 갱신되며, 로그가 늦게 쓰이면 표시도 늦습니다.

4. 요청과 답변을 보려면 `2열`을 해제해 카드 보기로 바꾸고 카드 제목을 누릅니다. 단순히 작업이 끝났다는 표시만 보는 데서 그치지 않고, 무엇을 요청했는지와 어떤 답변이 왔는지를 함께 읽습니다. 이어서 지시할 내용은 원래 에이전트에서 보냅니다.

5. 계속 볼 세션은 고정하고 검색·필터로 필요한 작업을 찾습니다. 당분간 안 볼 세션은 숨기고, 끝난 대화는 `waid에서 보지 않기`로 목록에서 정리할 수 있습니다. 원래 대화가 삭제되거나 에이전트가 종료되지는 않습니다. 다시 찾을 때는 검색어·필터를 지우고 `전체 보기`를 확인하세요.

세션이 안 보인다면 `전체 보기`부터 확인하고, 서브에이전트는 `보조 포함`도 켜보세요. 그래도 안 보이면 사용한 도구, 운영체제, 요청을 보낸 뒤 어떤 상태였는지 알려주시면 확인하겠습니다. Orca의 로컬 세션 복귀에는 실행 가능한 Orca CLI와 현재 세션 연결 정보가 필요하며, SSH 세션 복귀는 지원하지 않습니다.

### 본인 작업 방식에 맞게 고쳐 쓰셔도 됩니다

MIT 라이선스로 공개했습니다. 저장소를 클론해서 카드 배치나 필터, 로그 수집 방식을 본인 일하는 방식에 맞게 고도화해 쓰셔도 됩니다.

```sh
git clone https://github.com/laekhole/what-am-i-doing.git
```

직접 수정할 분들을 위한 빌드 방법은 [README](https://github.com/laekhole/what-am-i-doing#build-from-source)에 있습니다. 단순히 사용하려면 소스를 빌드할 필요 없이 EXE를 받으면 됩니다.

**추가했으면 하는 툴이 있다면 댓글이나 [GitHub 이슈](https://github.com/laekhole/what-am-i-doing/issues)로 요청해주세요. 로그 형식을 확인해 연동을 추가하겠습니다.** 도구 이름, 운영체제, 어떤 정보를 한눈에 보고 싶은지 적어주시면 도움이 됩니다. 업무 대화나 인증정보가 담긴 원본 로그를 공개로 올릴 필요는 없습니다.

로그와 대화 내용은 PC 안에서만 처리하고 외부로 전송하지 않습니다. 사용 통계도 수집하지 않습니다. 아직 초기 버전이며 EXE에 Windows 코드 서명(Authenticode)이 없어 SmartScreen이나 Smart App Control에서 실행이 차단될 수 있습니다. macOS 앱은 개발 중입니다.
