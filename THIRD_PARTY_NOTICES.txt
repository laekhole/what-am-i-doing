waid - Third-party notices
==========================

These notices accompany waid's own MIT license and the separate bundled
Pretendard font license. They do not replace or change those licenses.
The Windows Licenses and notices menu and desktop --licenses output include
all three notices.

Application dependency baseline: desktop/Cargo.lock, waid 0.2.0.
Rust library baseline: rustc 1.98.1 (48a229cea, 2026-09-01), with the matching
rust-src distribution. This file includes the library components relevant to
Windows MSVC and macOS, including optional backtrace support. A component's
presence here does not mean every function is retained by a particular linker.
Compiler executables, build tools, tests and libraries for other platforms are
not redistributed by waid and are not included in this list.

Maintainers: review this file whenever Cargo.lock, Rust, target platforms,
features, embedded assets or packaging change. In particular, a Mac release
must be checked against the Rust and Swift runtimes used for that release.
Platform system libraries loaded from Windows or macOS remain governed by
their respective platform terms; packaging additional runtime files requires
a separate review of their redistribution notices.

The application crate license texts below were copied from the packages in
Cargo's registry. Their package source URLs identify the exact versions.
For crates offering MIT as an alternative, waid uses the MIT option.
The Rust library texts were copied from the matching rust-src distribution
and share/doc/rust, with original copyright and permission notices retained.
File paths in the runtime sections are relative to that Rust distribution.
