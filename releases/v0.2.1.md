# waid v0.2.1 — English UI, tray summary and Microsoft Store package

v0.2.1 is a **Windows update** to the v0.2.0 milestone. Core and desktop packages are both `0.2.1`. Stabilization continues. macOS remains development work toward v0.3.0; this release distributes **Windows x64 only**.

[English guide](https://github.com/laekhole/what-am-i-doing/blob/v0.2.1/README.md) · [User guide](https://github.com/laekhole/what-am-i-doing/blob/v0.2.1/docs/USER_GUIDE.md) · [Full changelog](https://github.com/laekhole/what-am-i-doing/compare/v0.2.0...v0.2.1)

## Changes since v0.2.0

- **English and Korean UI:** switch with **English / 한국어** in the window or tray. New installations follow the system language; existing settings without a language stay Korean. The CLI (`--lang`, `WAID_LANG`) and local HTML dashboard are bilingual too. Prompts and answers are never translated.
- **Tray summary and reply notifications:** while the window is hidden, the tray shows status counts and badges for new replies or errors, with shortcuts to sessions waiting for you. Notifications are quiet and grouped, can be turned off or snoozed for one hour, and skip hidden, excluded and auxiliary sessions.
- **SSH screen observation:** Codex or Claude Code running in a plain SSH session can appear from the visible Windows Terminal screen as a screen-observation entry. Set `WAID_TERMINAL_SCAN=0` to turn it off.
- **Collection hardening:** parser bounds, SQLite copies, model/session metadata, Cursor, worktree and Orca collection, dashboard recovery and HTTP request validation were fixed. A partly broken JSON source now warns and keeps its readable rows.
- **Shorter display IDs:** session IDs start at 4 characters and lengthen only when two sessions collide, and are added only to titles that clash.
- **Embedded license notices:** waid's MIT license, third-party notices and the Pretendard OFL are built into the EXE. Open them from the tray menu or with `waid-desktop.exe --licenses`.
- **Microsoft Store package:** the release pipeline can build an MSIX for Microsoft Store distribution. Store installs are signed by Microsoft; the Store listing will be linked from the README once it is published.

## Download and upgrade

| Asset | Purpose |
|---|---|
| `waid-v0.2.1-windows-x64.exe` | Standalone Windows app; the only runtime file needed. |
| `waid-v0.2.1-windows-x64.exe.sigstore.json` | Detached signature bundle for verifying release-workflow origin. |
| `SHA256SUMS.txt` | SHA-256 checksum for the EXE. |

Follow the [checksum and Cosign verification steps](https://github.com/laekhole/what-am-i-doing/blob/v0.2.1/docs/USER_GUIDE.md#download-and-verify-a-release) before running the EXE. GitHub's automatic source ZIP/TAR files are source code, not the app.

To upgrade from v0.2.0, quit the old app through its tray menu and run the new EXE. Settings stay in `%LOCALAPPDATA%\waid\settings.json` (or your `WAID_DATA_DIR`); new fields for language and notifications are added with notifications on. There is no automatic updater.

The Microsoft Store version keeps its own settings under its package folder, so pins and hidden sessions from the EXE do not carry over, and uninstalling it removes those settings.

## Important limits

- **The EXE is still not Authenticode-signed.** Smart App Control or SmartScreen may block it; the Microsoft Store version avoids this once published.
- **Screen observation reads only what is visible.** Hidden tmux panes and inactive tabs are not collected, and status, context, remote path and conversation ID stay Unknown for these entries.
- **Tray notifications:** returning to the exact agent window from a notification, Do Not Disturb interaction, long runs and mixed-DPI setups have not been fully validated.
- The limits listed in the [v0.2.0 release notes](https://github.com/laekhole/what-am-i-doing/blob/v0.2.1/releases/v0.2.0.md#important-limits) still apply.

## 한국어

v0.2.1은 v0.2.0 Windows 단계의 **Windows 업데이트**입니다. 코어·데스크톱 패키지는 모두 `0.2.1`이며 안정화는 계속 진행합니다. macOS는 v0.3.0을 위한 개발 단계이고, 이번 배포 파일은 **Windows x64 전용**입니다.

### v0.2.0 이후 주요 변경

- **한국어·영어 화면:** 창 또는 트레이의 **English / 한국어**로 바꿉니다. 새로 설치하면 시스템 언어를 따르고, 언어 항목이 없는 기존 설정은 한국어를 유지합니다. CLI(`--lang`, `WAID_LANG`)와 로컬 HTML 대시보드도 두 언어를 지원합니다. 요청·답변 내용은 번역하지 않습니다.
- **트레이 요약과 답변 알림:** 창을 숨겨도 트레이에서 상태별 개수와 새 답변·오류 배지를 보고, 내 차례인 세션으로 바로 갈 수 있습니다. 알림은 조용히 묶어서 보여 주며 끄거나 1시간 미룰 수 있고, 숨김·제외·보조 세션은 알리지 않습니다.
- **SSH 화면 관찰:** 일반 SSH 세션에서 실행 중인 Codex·Claude Code를 Windows Terminal에 보이는 화면에서 읽어 화면 관찰 항목으로 표시합니다. `WAID_TERMINAL_SCAN=0`으로 끌 수 있습니다.
- **수집 안정성:** 파서 범위, SQLite 복사, 모델·세션 정보, Cursor·worktree·Orca 수집, 대시보드 복구, HTTP 요청 검증을 고쳤습니다. 일부가 깨진 JSON 소스는 경고를 띄우고 읽을 수 있는 항목은 유지합니다.
- **짧은 표시 ID:** 세션 ID는 4자로 시작하고 겹칠 때만 길어지며, 제목이 겹치는 경우에만 붙습니다.
- **라이선스 고지 내장:** waid MIT 라이선스, 타사 고지, Pretendard OFL을 EXE에 넣었습니다. 트레이 메뉴나 `waid-desktop.exe --licenses`로 볼 수 있습니다.
- **Microsoft Store 패키지:** Store 배포용 MSIX를 만들 수 있게 했습니다. Store 설치본은 Microsoft가 서명합니다. Store 등록이 공개되면 README에 링크를 추가합니다.

### 다운로드·업그레이드

`waid-v0.2.1-windows-x64.exe`, 같은 이름의 `.sigstore.json`, `SHA256SUMS.txt`를 내려받아 [체크섬·Cosign 검증](https://github.com/laekhole/what-am-i-doing/blob/v0.2.1/docs/USER_GUIDE.ko.md) 후 실행하세요. 실행에는 EXE만 필요합니다.

v0.2.0에서는 트레이 메뉴로 기존 앱을 종료하고 새 EXE를 실행하면 됩니다. 설정은 `%LOCALAPPDATA%\waid\settings.json`(또는 `WAID_DATA_DIR`)에 그대로 있고, 언어·알림 항목이 추가되며 알림은 켜진 상태로 시작합니다. 자동 업데이트는 없습니다.

Microsoft Store 버전은 패키지 전용 폴더에 설정을 따로 저장하므로 EXE의 고정·숨김 설정은 넘어가지 않고, 앱을 제거하면 그 설정도 지워집니다.

### 주의사항·검증

- EXE는 아직 Authenticode 서명이 없어 Smart App Control·SmartScreen이 차단할 수 있습니다. Store 버전이 공개되면 이 문제가 없습니다.
- 화면 관찰은 보이는 화면만 읽습니다. 숨은 tmux 창·비활성 탭은 수집하지 않으며 상태·컨텍스트·원격 경로·대화 ID는 미확인입니다.
- 알림에서 정확한 에이전트 창으로 복귀, 방해 금지 모드, 장시간 실행, 혼합 DPI는 충분히 검증하지 않았습니다.
- [v0.2.0 릴리스 노트](https://github.com/laekhole/what-am-i-doing/blob/v0.2.1/releases/v0.2.0.md#한국어)의 주의사항도 그대로 적용됩니다.

커밋 `1239f39`의 Windows·Linux CI(Windows 코어 108·CLI 7·데스크톱 40(환경 의존 4개 제외)·단일 EXE 1, Linux 코어 104·CLI 7)와 macOS 검사가 통과했습니다. 태그 릴리스 워크플로는 Windows 테스트·EXE 빌드·Sigstore 서명 검증을 다시 수행한 뒤 게시합니다. 이전 로컬 전체 실행에서 JSON 복구 테스트가 한 번 실패했다가 단독 재실행에서 통과한 기록이 있으며 원인은 아직 확인하지 못했습니다.
