# waid v0.2.0 — Windows session overview

v0.2.0 is the **Windows milestone**, with core and desktop packages both at `0.2.0`. Stabilization continues; this is not the v1.0.0 stable milestone. macOS AppKit code is included for development toward v0.3.0, but this release distributes **Windows x64 only**.

[English guide](https://github.com/laekhole/what-am-i-doing/blob/v0.2.0/README.md) · [한국어 안내](https://github.com/laekhole/what-am-i-doing/blob/v0.2.0/README.ko.md) · [Full changelog](https://github.com/laekhole/what-am-i-doing/compare/v0.1.0...v0.2.0)

## Changes since v0.1.0

- **One Windows EXE:** the native app now contains its collector and Pretendard fonts/license. No installer, extraction, companion executable, Rust, Node or WebView2 is needed to run it.
- **Richer session cards:** expandable latest prompt, last logged answer and first prompt; prompt copying; one-column cards and a two-column list; clearer project/model placement, harness logos and relative dates.
- **Context visibility:** Codex logged token usage/limit, Claude input/cache token measurements and explicit compaction evidence. Windows cards and the two-column list emphasize 25% or less remaining and observed compaction without opening details. Unknown limits stay unknown.
- **Better organization and status tracking:** recent-activity view, Show all, auxiliary filtering, explicit “Do not show in waid,” manual restore and automatic revival on a distinguishable new request. Pre-launch active history starts Unknown with a separate last-logged status; observed work does not time out to idle.
- **Session return:** exact existing local Orca terminal matching, manually associated ChatGPT conversation links and supported classic PowerShell/ChatGPT/Claude desktop windows. Stale or ambiguous targets are refused with an explanation.
- **Orca SSH visibility:** read available remote session metadata from Orca's existing local hook mirror, with launch checks and in-process retention. No SSH connection or remote input is performed.
- **Reliability and compatibility:** full source identities in JSON schema 2, unambiguous migration of old settings keys, improved repeated-request and log-replacement handling, source warnings, last-good-list retention and collector child cleanup. Minimize now stays on the taskbar; Close hides to the tray.
- **Mac development:** native AppKit list/details, shared session organization/settings, template editing, clipboard and supported return actions; Apple Silicon/Intel development bundles and smoke/restart CI. These are not Mac release artifacts.

Search/filter, pin/hide, always on top, 0–60% Windows transparency, keyboard navigation and Daylight/Midnight JSON template preview/import/export are available. waid processes logs locally with no telemetry, cloud sync or external AI API calls. It does not edit source conversations or send prompts to agents.

## Download and upgrade

| Asset | Purpose |
|---|---|
| `waid-v0.2.0-windows-x64.exe` | Standalone Windows app; the only runtime file needed. |
| `waid-v0.2.0-windows-x64.exe.sigstore.json` | Detached signature bundle for verifying release-workflow origin. |
| `SHA256SUMS.txt` | SHA-256 checksum for the EXE. |

Download all three matching files and follow the [PowerShell checksum and Cosign verification steps](https://github.com/laekhole/what-am-i-doing/blob/v0.2.0/README.md#download-and-verify-a-release) before running the EXE. GitHub's automatic source ZIP/TAR files are source code, not the app.

To upgrade from v0.1.0, quit the old app through its tray menu, back up `%LOCALAPPDATA%\waid\settings.json` (or your `WAID_DATA_DIR`) and run the new EXE. Settings stay in the same location. The old companion `waid.exe` is no longer required by the desktop app. There is no automatic updater.

## Important limits

- **Logs are evidence, not a live-window inventory.** Missing/late logs and bounded reads can omit information. The first launch baseline is Unknown for old working/waiting history; CLI status uses a different, 20-second activity rule.
- **Support varies by source.** Claude Code/Codex have real-log checks; Cursor has one real local database check. Copilot CLI remains fixture-only; other registered JSON readers are experimental; Aider/Goose are detection-only. Non-JSONL sources remain Unknown for turn status.
- **Context is not a quota or quality score.** Claude's active context limit is unavailable; unmeasured sources remain unknown. Compaction evidence can fall outside the read range after restart.
- **Exclusion does not stop or delete a conversation.** Automatic restoration needs a distinguishable new user request, not merely reopening a window. Settings can retain prompts/answers; use one app instance per settings file.
- **Return targets differ.** Windows Terminal/VS Code individual tabs and direct Claude conversation selection are unsupported. Restarted windows need reconnection. A saved ChatGPT link was checked against app navigation, but complete physical-click/focus walkthroughs remain pending. SSH return is unsupported.
- **Signing is detached Sigstore, not Authenticode.** Smart App Control/SmartScreen may still block execution. Accessibility, mixed-DPI and long-duration real-use validation remain incomplete.
- **macOS is development-only.** Its context summary is available in details; list badges and full token/timestamp details are not yet exposed. Developer ID signing/notarization, Finder installation on a clean machine, real-agent return and minimum-OS acceptance remain pending. Android, iOS/iPadOS and waidaway LAN access/prompt delivery are not implemented.

## 한국어

v0.2.0은 **Windows 사용 가능 단계**입니다. 코어·데스크톱 패키지는 모두 `0.2.0`이며 안정화는 계속 진행합니다. v1.0.0 안정화 완료 단계는 아닙니다. macOS 코드는 v0.3.0 개발용으로 포함되지만 이번 배포 파일은 **Windows x64 전용**입니다.

### v0.1.0 이후 주요 변경

- **EXE 하나로 실행:** 수집기·Pretendard 글꼴·라이선스를 내장했습니다. 설치·압축 해제·동반 EXE·Rust·Node·WebView2 없이 실행합니다.
- **대화 카드 개선:** 최근 요청·마지막 기록 답변·첫 요청 펼치기, 요청 복사, 1열 카드·2열 목록, 프로젝트·모델 배치, 하네스 로고와 상대 시각을 제공합니다.
- **컨텍스트 확인:** Codex 사용 토큰·한도, Claude 입력·캐시 토큰과 명시적 압축 기록을 읽습니다. Windows에서는 25% 이하 남음·압축됨을 접힌 카드와 2열 목록에서도 강조합니다. 없는 한도는 추정하지 않습니다.
- **정리·상태 개선:** 최근 활동 보기, 전체 보기, 보조 세션 필터, 목록 제외·되살리기와 구별 가능한 새 요청에 따른 자동 복귀를 지원합니다. 시작 전 작업 중·내 차례 이력은 미확인과 마지막 기록으로 나누며 관측한 작업을 시간만으로 유휴로 바꾸지 않습니다.
- **세션 복귀:** 정확히 일치하는 기존 로컬 Orca 터미널, 직접 연결한 ChatGPT 대화 링크·클래식 PowerShell 콘솔·ChatGPT/Claude 앱 창으로 이동합니다. 오래되거나 모호한 연결은 거절하고 이유를 표시합니다.
- **Orca SSH 표시:** Orca의 기존 로컬 훅 사본에서 원격 세션 정보를 읽고 실행 정보를 검증하며 현재 waid 실행 중 관측 이력을 유지합니다. SSH 접속·원격 입력은 수행하지 않습니다.
- **안정성·호환성:** JSON schema 2 전체 식별자와 안전하게 대응 가능한 이전 설정 이관, 반복 요청·로그 교체 처리, 소스 경고·마지막 정상 목록 유지·소유 수집기 정리를 개선했습니다. 최소화는 작업 표시줄에 남고 닫기는 트레이로 숨깁니다.
- **Mac 개발:** 네이티브 AppKit 목록·상세, 공용 정리·설정, 템플릿·클립보드·일부 세션 복귀와 Apple Silicon/Intel 개발 패키지·자동 검사를 추가했습니다. Mac 릴리스는 아닙니다.

검색·필터·고정·숨김, 항상 위, Windows 투명도 0~60%, 키보드 조작, Daylight/Midnight JSON 템플릿 미리보기·가져오기·내보내기도 사용할 수 있습니다. 로그는 로컬에서 처리하며 통계 수집·클라우드 동기화·외부 AI API 호출·원본 대화 수정·프롬프트 전송을 하지 않습니다.

### 다운로드·업그레이드

`waid-v0.2.0-windows-x64.exe`, 같은 이름의 `.sigstore.json`, `SHA256SUMS.txt`를 내려받아 [PowerShell 체크섬·Cosign 검증](https://github.com/laekhole/what-am-i-doing/blob/v0.2.0/README.ko.md#릴리스-다운로드와-검증) 후 실행하세요. 실행에는 EXE만 필요합니다. GitHub가 자동 제공하는 Source code ZIP/TAR는 실행 파일이 아닙니다.

v0.1.0 사용자는 트레이에서 기존 앱을 종료하고 `%LOCALAPPDATA%\waid\settings.json`(또는 지정한 `WAID_DATA_DIR`)을 백업한 뒤 새 EXE를 실행하세요. 설정 경로는 같고 새 데스크톱에는 과거 동반 `waid.exe`가 필요 없습니다. 자동 업데이트는 없습니다.

### 주의사항·검증 범위

- 로그 뷰어이므로 현재 열린 창을 보증하지 않으며 늦은 기록·제한된 읽기 범위로 누락될 수 있습니다. 실행 전 작업 중·내 차례는 미확인으로 시작하고 CLI는 별도의 20초 활동 기준을 사용합니다.
- 실로그 검증은 Claude Code·Codex와 Cursor DB 1개입니다. Copilot CLI는 합성 입력만 확인했고 다른 JSON 리더는 실험 단계, Aider·Goose는 감지만 지원합니다. JSONL 이외 소스의 턴 상태는 미확인입니다.
- 컨텍스트는 마지막 측정값이며 계정 잔량·품질 점수가 아닙니다. Claude 한도와 미측정 소스는 미확인이고 재시작 후 읽기 범위 밖 압축 기록은 사라질 수 있습니다.
- 목록 제외는 대화 삭제·중단과 무관하며 자동 복귀는 구별 가능한 새 요청이 필요합니다. 로컬 설정에 요청·답변이 남을 수 있고 설정 파일당 앱 하나 사용을 권장합니다.
- Windows Terminal·VS Code 개별 탭, Claude 대화 직접 선택, SSH 복귀는 미지원입니다. 창 재시작 후 재연결해야 합니다. 저장한 ChatGPT 링크 이동은 확인했지만 전체 연결 클릭·포커스 흐름은 검증이 남아 있습니다.
- Sigstore는 Authenticode가 아니므로 Smart App Control·SmartScreen이 차단할 수 있습니다. 접근성·혼합 DPI·장시간 실사용 검증도 남아 있습니다.
- Mac은 개발용이며 상세의 컨텍스트 요약만 연결되어 있고 목록 배지·전체 토큰/시각 상세는 아직 표시하지 않습니다. Developer ID 서명·공증·깨끗한 환경의 Finder 설치·실제 세션 복귀·최소 OS 검증이 남아 있습니다. Android·iOS/iPadOS·waidaway LAN·원격 요청 전달은 미구현입니다.

코드 `47f4317`의 Windows CI **130개**(환경 의존 3개 제외), Mac 아키텍처별 Rust **121개**(각 1개 제외)와 AppKit 스모크·재시작 검사가 통과했습니다. 태그 릴리스 워크플로는 Windows 테스트·단일 EXE 빌드·Sigstore 서명 검증을 다시 수행한 뒤 게시합니다. 위 자동 검사와 [검증 기록](https://github.com/laekhole/what-am-i-doing/blob/v0.2.0/VALIDATION.md)의 실환경 확인 범위를 구분해 참고하세요.
